# 西子科技口播制作

先读取[风格规范](references/style.md)与[制作流程](references/workflow.md)。用户本期明确要求优先于本Skill默认；继承已选项，返修保留无关合格内容。

## 开始执行

核实原片、原声、用户提供的本期BGM、用途、画幅、已有字体、参考与实际制作环境。没有上期选择的新使用者，先明确必要输入，不假设拥有作者原片、参考或工具。

默认内部验证难点后直接制作全片，再集中返修，不设样段审批。每句有语义视觉回应；人物与卡片不设固定比例；重点句推近后保持；海报配色按段落控制强弱。使用原始人物，不重画人脸。

需要网络画面时读取[素材规则](references/materials.md)：MotionGit免费API候选须先经用户选定，再下载或引用；不另行付费生成。此确认不阻止无依赖工作。

按实际环境实现和检查，不要求安装特定插件。本包是制作方法与规范，不是一键渲染程序。交付前区分技术、完整视听与用户验收；未完成必要视听时标为待检查预览，不能因解码通过宣布成片验收。
