# MotionGit 免费素材工作流

1. 实际使用时读取官方说明：https://motiongit.com/developers/media 和 https://motiongit.com/developers/creator-guide 。核实当前免费检索能力、权限、额度、认证及模板要求，不凭历史信息猜接口。
2. 用户提供自己的合法访问条件。包内没有Key、账号或付费模板；不要搜集无关凭据、暴露密钥或代替用户购买。缺少访问条件时说明具体缺口，继续不依赖素材的工作。
3. 按口播语义、模板/工程比例、构图和风格检索现成画面；不调用付费生成，不把别处搜索冒称MotionGit结果。
4. 候选清单列：编号、预览/来源页、拟用句子与位置、比例/分辨率、来源平台、作者、原始链接、许可名称与链接、署名要求及文本。未知信息如实标注；免费检索不等于无限制使用。
5. 等用户选定后，再按来源允许方式下载或引用到工程。未选定不下载素材文件、不正式入片；许可不支持用途时说明，不能因已选中就直接使用。
6. 保存素材编号、来源、查询日期、许可依据、用户选择、本地文件或引用、入片位置、署名落实方式；引用链接失效时不要冒充已归档。

海报配色参考不授予海报图像的入片许可。资料画面、示意和实际产品录屏必须区分，不用库存镜头伪装真实测试。
