# lrh的包装插件

先读取[风格规范](references/style.md)与[制作流程](references/workflow.md)。首次安装、换电脑、缺少工程或效果明显偏离参考时，先按[运行环境与迁移](references/runtime.md)核实并建立工程。用户本期明确要求优先于本Skill默认；继承已选项，返修保留无关合格内容。

## 开始执行

核实原片、原声、用户提供的本期BGM、用途、画幅、已有字体、参考与实际制作环境。没有上期选择的新使用者，先明确必要输入，不假设拥有作者原片、参考或工具。

默认内部验证难点后直接制作全片，再集中返修，不设样段审批。每句有语义视觉回应；人物与卡片不设固定比例；重点句推近后保持；海报配色按段落控制强弱。使用原始人物，不重画人脸。

需要网络画面时读取[素材规则](references/materials.md)：MotionGit免费API候选须先经用户选定，再下载或引用；不另行付费生成。此确认不阻止无依赖工作。

## 实际制作链路

默认采用单独授权的 Agent Motion 工程、JavaScript/Three.js 与浏览器逐帧渲染；FFmpeg 负责素材处理、混音、合成与编码。完整发行包附带锁定提交的上游运行源码压缩包，轻量安装提供校验下载入口；依赖、浏览器与模型仍需首次联网安装。上游采用非商业许可证，详见[运行说明](references/runtime.md#许可与范围)，不能沿用本Skill的MIT许可宣称引擎可商用。

读取实际工程的 `AGENTS.md` 及其中的 Motion Craft、SRT 与参考驱动制作技能，按适用阶段推进。记录真实工程路径、源码版本、设计实现文件和渲染命令。安装本Skill、运行FFmpeg、安装Three.js都不能证明已经使用Agent Motion。

用户指定其他编辑器或已有合格链路时保留其选择。环境缺失时先修复具体缺口；不能未经说明把主UI与空间动画替换为字幕绘图和统一整页翻转。替代实现须通过同一代表片段的可读性、空间关系、状态交接检查，确认的是能力，不唯工具名称。

制作前读取[视觉质量与参考迁移](references/quality.md)，内部完成开场或最难关系段的连续验证后自主扩展全片，不增加逐段审批。附带[原创验证场景](assets/quality-demo/index.html)用于检验环境和交接机制，不是完整口播模板或V6复制品。

交付前区分技术、完整视听与用户验收；未完成必要视听时标为待检查预览，不能因解码通过宣布成片验收。本Skill及安装器都不是输入原片即可一键获得已验收影片的程序。
