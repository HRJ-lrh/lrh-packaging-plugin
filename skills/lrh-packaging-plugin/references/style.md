# 科技口播风格规范｜公开版 1.0.0

根据西子2026-11-03现行规范整理。具体素材与本期选择由使用者提供，本文不附带历史成片。


### 整体观感与节奏
- 目标是抓眼、利落、有质感、有张力，并追求更酷炫的空间表现；不承诺播放量或“必爆”。
- 以连续动作、空间关系、语义推进和阅读停稳作为最低标准：人物、文字、图形与窗口随语义改变主次、位置和尺度，动作前后有接力。不能只换颜色、字体或入场方向，却持续重复相同构图与逐张卡片展示。
- 动作幅度敢做，启动与交接要快，落定干净；用短促弹性收尾，不持续晃动。
- 开场、知识点、转折突出，阅读与解释处停稳，不能把“全程包装”误解成每秒闪切。
- 每句话都要有对应的视觉回应，可以是例子、图解、卡片、花字、标记或人物关键帧，不等于每句新增卡片或切镜。保留正确口播和自然节奏；单句时间不足时简化为最能解释意思的一步，不强行加速、不为动画延长或重排口播。

### 构图饱满度与内容密度
- 同时检查画面外部留白和卡片内部空白。人物、主信息与必要的辅助内容共同组织画面；不能只把卡片放大，内部仍只有几个字，也不能把“饱满”变成塞满文字。
- 卡片内容优先级：具体例子/前后对比 → 关系图解 → 过程演示 → 真实操作/资料；这是表达偏好，不是每段必含四项，也不能代替必须有来源的事实证据。允许自主补充贴合语义的原创例子和示意，不虚构事实、数据、产品能力或实测效果。禁止空卡片、无关装饰和仅重复口播关键词。
- 简单句用单个辅助提示，复杂句可用同一组内容分步揭示、变化并汇成结果；不要默认整张卡片连内容一起弹出。矩形、圆形、三角形和不规则形状按内容选择，不为凑形状而堆元素。
- 开场、人物主讲、过程演示、结果总结、结尾五类代表构图须在早期查看；可以用同一代表片段覆盖多类，不要求先把全片静态页定稿。主信息在实际观看尺寸下清楚，辅助内容不抢脸、不压字，并留足阅读时间。
- 角标、细线、进度点和开放式边框可作为边缘组织手段，按本片风格选择；不能代替内容，不能穿过必读文字或脸部，也不伪造录制状态、来源或数据。

### 网络素材检索与选用（后续视频）
- 后续视频需要现成网络画面时，通过MotionGit已开放的免费素材检索API查找；优先匹配口播语义、所用模板/工程画幅比例、构图和风格。不为补素材另行付费生成；不因API不可用而擅自改用付费服务。
- 使用时核实实际接口、权限和免费额度；缺少访问条件、额度不足或检索不可用时如实说明，不将其他渠道的搜索结果冒称MotionGit返回。
- 先提供候选预览或来源页、对应口播位置、比例/分辨率与适配说明、来源平台及作者、原始链接、具体许可及许可链接、署名要求和可用署名文本。信息未知明确标注，不把“免费检索”视为无限制使用许可。
- 等用户选定后，再按来源许可及平台允许的方式下载或引用到本地工程；选定前不下载素材文件、不正式入片。许可未明或不支持拟定用途的素材不得因被选中而直接使用，应说明缺口。
- 在工程保存来源、许可、署名、用户选择和本地文件/引用的对应记录，交付时落实必要署名。网络素材选定是“直接制作全片”流程的明确例外；等待期间可继续无依赖工作，不重复确认已选素材。

### 参考学习与迁移
- 分析参考的信息密度、人物占比、主辅层级、颜色分工、对象关系、动作顺序和接力方式，不能只摘取一个翻面或缩放效果。
- 在已有PLAN中将参考的具体时段对应到本期语句：要解释什么、借鉴什么机制、如何用本期素材和内容改写。外层播放器、黑边、标尺和教程操作指令与实际包装分开判断。
- 选定动作检查连续过程，采样范围和未完成的视听如实记录；风格借鉴不等于直接使用他人成片素材，也不等于已达到参考完成度。

### 背景与配色
- 配色主动汲取文化艺术/展览海报和电影海报：前者参考大胆色块、撞色与主辅面积关系，后者参考整体色调、光影与情绪。结合本期内容及人物原景重新设计，不局限于从服装和背景吸取近似色，也不固定历史配色。学习色彩组织，不直接搬用海报图像或构图。
- 按段落控制用色力度：人物段相对克制，协调自然肤色和原景；独立演示段允许高饱和、强撞色，仍须文字清楚、主次明确。允许鲜亮颜色，不以一律降低饱和度解决不协调，也不要求每张卡片都鲜艳。
- 海报配色进入视频时同时设计主辅色面积、明暗、文字及卡内图形。跨段通过共同强调色、过渡色或色块承接等方式连接，检查人物段→演示段→人物段完整过程，不能只看单张静帧。
- 第一轮B暖奶油橙黄、第二轮暖灰炭黑加冰蓝，作为可复用风格实例保留，而非强制默认。
- 背景、人物容器、主信息卡及卡内图形必须有可见的明暗和主次层级，避免全是近似浅色而糊成一层。先确定基础色、主信息色与强调色的职责，再判断是否需要增加颜色。
- 多卡组合必须放进完整构图一起评估，同时检查人物原景、文字对比、材质与阴影；不能单卡各自好看，组合后却冲突。调整卡片颜色时同步检查内部小图、按钮、轨道和文字，不只换底色。
- 背景保持较大运动范围与弹性，给画面活力；降低装饰存在感以保护内容，不压脸、不干扰必读文字。
- 保留已制作的风格变体，不强制所有新视频沿用同一套颜色。没有新方向时沿用本规范的质量与制作规则，结合原片自主搭配，不重新要求用户说明整套风格；字体继承上次已选字体，背景音乐每期主动询问并由用户提供。

- 配色可在中性色配少量强调色、多色分工之间按内容选择，不固定公式；关键是卡片之间及其与原景的饱和度、明暗和面积关系协调，避免局部突兀抢眼。参考动作不意味着照搬参考配色。
- 主卡片优先硬质实体感：清楚的边缘、适量厚度、统一受光与柔影；周边辅助提示可轻薄。材质随角色区分，不把全部元素做成相同厚卡。

### 字体、大字与人物
- 默认继承使用者上次已选且许可清楚的字体；首次使用可建议得意黑，需核实可用字体文件与许可；这是可随用户后续选择更新的默认，不是永久固定字体。每期不再强制字体候选选型。用户要求换字体或选型时提供实际效果；辅助信息可用易读无衬线字体，真实页面不换字。
- 字面、轮廓、挤出厚度与后方投影分别控制。避免模糊字面、叠出重影或形成大片脏灰；需要柔和阴影时允许只模糊后方投影，并保留清晰字面。不能将旧版对某种模糊投影的否定解释为永久禁止柔影。
- 花字按背景复杂程度处理：复杂背景加强明暗对比、窄轮廓和柔影，干净背景适当减轻，不统一套重立体。字面清楚，可有短厚度、近处接触影及柔和后投影；字幕、小UI文字分别设计。检查实际4K导出及缩小播放效果，阴影参数需随渲染尺度适配，不能只看编辑预览。
- 更换字体后重新检查视觉分量、行宽、字距、斜体外伸、长句和运动边界；不能只换字体文件便沿用旧排版。明确指定字体时直接使用，不重复选型。
- 身后大字默认偏高、足够大、可有透明渐变、无描边；前景花字按本片对比与体积需要处理，用户明确要求优先。人物遮挡约40%是构图参考，不机械按像素计算；必须仍能辨认文字，保护面部。
- 人物原景、人物窗和独立演示按内容选择，不设置固定时长比例。人物原景上可以叠加卡片，不能把两者当作互斥选项；重要演示允许暂时完全接管画面。不得将个别作品的镜头分配复制为后续固定时码。
- 人物重点句短促推近后停稳，不自动缩回；较长普通讲述可以缓慢推进，同时保留稳定段落。下一镜重新取景，不无限累积放大，也不按固定秒数机械缩放。
- 人物全画幅、小窗、圆框和矩形随语义转换，不能永远固定右上角。
- 缩放保持原比例，变换取景框时重新裁切；默认让脸与上半身在小窗内部视觉居中，容器居中不等于人物居中。人物因语义移到画面一侧时，小窗内部仍需独立取景。脸、帽子、嘴部和关键手势不被误切；检查移动与形变全程，遮罩与原片逐帧同步。
- 人物与包装同屏时，面部、嘴部和字幕保持清楚；身体其他区域可按演示需要遮挡，不强制整个上半身无遮挡。独立演示允许完全替换人物画面；这不同于同屏时用卡片误挡脸。连线和装饰不得穿过必读文字，检查全轨迹。
- 优先原始高清人物；需要清晰度处理时只做保守增强，不重画五官、不改变人脸样貌。

### 抖音界面避让（2026-11-02新增）
- 后续字幕、重点花字（含人物身后大字）、标题、卡片中的必读文字和关键数字，尽量避开抖音顶部界面、右侧互动按钮，以及底部账号、描述、音乐和导航区域。不能只按干净成片判断可读性。
- 装饰、背景和出入场轨迹可延伸到边缘；信息正式揭示与阅读停留时必须清楚可读，不能让右侧按钮盖住末字或底部文案盖住字幕。空间运动需检查全轨迹，兼顾人脸避让。
- 每期预览提供可开关的抖音模拟遮挡层，检查首次揭示、最大缩放、视角变化、阅读停留和接出。检查层仅用于预览验收，不烧录进最终MP4。已有成片不因本条自动标为已检查通过。

### 动效与衔接
- 已认可动作库：二维到三维倾斜/硬质转面、短促甩入回弹、定点推近、固定窗口内结果横向接管、步骤激活弹起、人物圆框吸入/弧线换位、图库分列合拢、图文双卡、分类抽屉、指令弧线传递、素材回收。
- 固定质量与质感，不固定镜头排列。内容适合时允许复用已认可效果，不要求每条全部原创；但不能连续几段使用同一种包装，尤其不能全片只用倾斜交接。判断相似性同时看构图、容器、空间关系、动作顺序与信息揭示方式，不能仅靠换颜色或移动方向冒充新包装。
- 在已有PLAN先列同一段及相邻段的动作顺序，检查重复与语义对应。反复调节可以表现重试，但不能用同一滑入循环代替整个过程；改变动作要改变信息关系，不只是换方向。
- 同一对象、容器、阅读位置能延续就延续；设计前段退出、交接和后段进入，不能整段突然消失后另一侧跳出。人物原景与人物窗转换要连续重新取景、保持比例，避免两个人物叠影；字幕作为稳定屏幕层，不随人物窗缩放。
- 动效丰富优先体现两件事：同类动作不机械连续重复；动作解释比较、关系、调整或结果等内容。不以增加随机特效次数代替这两项。
- 不把拖沓的波浪弯曲、拉长吸入或统一整页翻页当作已认可网页模板。人物圆框吸入与网页被拉长是不同机制。
- 网页窗口在进出场可大幅运动，讲操作时回正停稳。图片与文字按各自实际边界独立采样，不硬切整张网页，比例不拉伸，重要内容不截断。
- 同一画布保持固定纹理尺寸，通过绘图变换适配卡片，防止上一页残留；抽查出入场中间态，不能只看最终静帧。

### 结尾与人物主次
- 结尾单独确定观看任务：人物收束、结果总结或行动提示。纳入内部代表片段验证，不等整片完成才补。
- 人物主导的结尾优先考虑原景满幅或更大的主体占比，不能惯性沿用“小人物＋大空卡”。如使用人物窗扩展，需连续重新取景，保持比例、原貌与关键手势。
- 名称、数字和关注提示按层级排布；开放式边框可辅助填充和组织两侧，但避开脸、指尖、字幕及平台界面。人物全屏、具体边框形式和字号属于本片取舍，不设为所有视频统一结尾。

### 空间感：下一阶段重点
- 前后层次、镜头运动、立体物体与材质三者结合，由内容决定；不以影响阅读和人脸为代价。
- 镜头角度变化不能仅由单张卡片左右歪斜替代；通过场景内多个对象的透视、远近尺度、遮挡、视差与焦点变化，表现统一的空间关系。真实3D或2.5D均可，以实际观感验收，不把实现方式说成参考作者的真实工程做法。
- 先让观众理解空间位置，再快速改变视角；到必读信息时减速并稳定。不得靠持续摇晃、文字模糊和大量无意义粒子制造“酷炫”。

### 包装库：风格与模块两层
- 第一层为整套风格：颜色关系、字体角色、布局、空间与材质、运动节奏、声音搭配。
- 第二层为可组合效果模块：按提问、对比、步骤、列举、数字、结果、总结等表达任务组织，记录适用内容、构图、运动、相邻衔接和安全限制。
- 同类内容可以有多种包装；不同模块组合时保持本片颜色、字体、材质与节奏协调。
- 新效果先内部验证实际口播、揭示、阅读和衔接，可随全片一起呈现并标注对应句子，经用户明确认可后才收入正式库；入库认可不构成全片制作的前置审批。参考视频被用户喜欢，仅代表方向认可，不等于自制效果已获验收。
- 库分为“正式可复用”和“候选参考/待验收样片”。候选可以存档，但不能标为正式。已有验收效果按内容复用无需每次重新审批；新组合或新方向先内部验证，再进入全片，正式入库仍需明确认可。
- 每个模块记录预览、工程、语义用途、使用记录、认可依据及禁用条件。制作时检查相邻段落和既有同类作品，避免机械重复；用户允许适合内容的合理复用，不人为设定禁用次数。

### 声音
- 背景音乐：每期主动向用户询问，由用户提供曲目或文件；已提供时直接使用。未提供前可继续视觉制作，不自行选曲、生成音乐或沿用上一期BGM作为最终配乐。曲目长度或使用范围有问题时说明并询问，不擅自换曲。动作音效继续沿用已认可的自主选取方法。
- 保留认可的科技感、弹性与重点提示搭配。知识点要有明确听觉提示，不全片只用一个“叮”。
- 按揭示、点击、复制、转面、落定、收尾区分音色与强度，不给每个字堆音效。代表连续样段就加入已有原声、用户提供的BGM和对应动作声，声音落点随动作共同调整，不等全片导出后才补。
- 可直接从许可清楚的音效库下载选择，不强制生成，不重复确认既定找法。可考虑有清晰许可的音效库；具体下载项需核实许可，不将库名视为授权凭据。
- 人声优先，讲话时音乐退让；动作音效同步视觉落点，尾音自然衔接。保留分轨，最终统一混音，不把多次归一化叠加。

### 制作、选型与交付
- 默认直接制作完整视频，交付后集中修改；内部代表片段用于制作方验证，不要求用户逐阶段确认。网络素材须先由用户选定再下载或引用；其他只有缺失必要输入、真实需求冲突或用户主动要求选型时才提问；不因新效果本身自动增加样片审批。
- 本Skill已经确认的规则自主执行。新内容先内部验证最复杂的衔接，再扩展全片；只有真正未定的取舍才询问。
- 每期先明确画幅，已确认的画幅在返修中继承；横屏4K为3840×2160，竖屏4K为2160×3840，动画60fps。原片与历史竖屏默认冲突时先明确，不擅自裁成竖屏。真实30fps素材保持原采样，不宣称凭空增加真实运动细节。
