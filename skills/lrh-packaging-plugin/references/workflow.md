# 科技口播制作流程：当前执行版

更新：2026-11-11。只维护执行顺序、工具触发和完成条件；具体视觉标准统一见[现行规范](style.md)，避免多处重复改写。

## 1. 开工入口与边界

1. 读现行规范（先看第1节反复强调项与第2节保留默认）、本流程、[最新参考](reference-catalog.md)、[包装库](packaging-library.md)，以及本期已有PLAN。
2. 最新用户要求优先；不以记忆摘要、旧案例、归档、“本期”历史参数或参考中的教程指令覆盖现行规则。
3. 默认内部验证后自主完成全片，交付后集中返修；不新增字体候选或样段审批。已明确的画幅、字体、BGM和修改项直接继承。
4. 只有缺失必要输入、真实需求冲突或用户要求选型时询问。保留的明确例外：后续视频网络画面候选先由用户选定，再按许可下载/引用；等待时继续无依赖工作。用户已授权的选项不重复确认。
5. 当前V6是空间、流畅动作和转场的质量对照，不是固定模板；参考实例、用户验收与实际检查分别记录。

## 2. 每次必须经过的步骤

| 阶段 | 做什么 | 完成条件及记录 |
|---|---|---|
| 1 输入与继承 | 核原片、原声、时长、画幅、发布方式、字体、用户BGM、交付软件；新片独立目录，返修沿用现工程 | 已明确不重问；未给BGM先问，不自行选曲；PLAN记本期选择，不改通用默认 |
| 2 安全区先行 | 按画幅读取用户11月11日横屏或竖屏纯净安全框，按实际线位建立可开关内/外框与对应字幕定位（横版底部带、竖版下三分线），再放文字和包装；旧暂定比例停用 | **所有包装内框内；横版字幕下方两线之间，竖版字幕在画面下三分线处（距顶部约2/3）；完整动态轨迹受约束**；具体边界只维护在规范第3节，不能凭记忆猜 |
| 3 可用时间线 | 自动转写、校对专名数字，核对句子与关键词时点，保留未授权删改的原声/语序 | 剪辑变动同步SRT与时间映射；句级不冒充词级，转写不冒充核听 |
| 4 语义与参考 | 每段明确“具体对象→变化→结果→交给下一段什么”，记录相关参考文件/时段、采用机制与本期改写 | 每句有视觉回应；看完整交接，记录实际采样/视听范围；不只提取关键词、不直接照抄镜头 |
| 5 必要资产 | 复用合格原始人物、遮罩、字体；准备真实资料/实录，示意清楚标注；需要网络画面则按规范第7节选取 | 许可、来源、分辨率及用途有据；MotionGit接口/免费额度不可用如实说，不擅自付费替代；先选后取 |
| 6 代表构图与配色 | 覆盖开场、人物主讲、过程、结果、结尾；先做具体UI内容，再看材质、层级、背景与人物协调；找艺术/展览和电影海报的色彩组织参考 | 在实际缩小观看尺寸仍清楚；薄卡/空卡/同构图先改；字体换后重排；透视花字按语义选择，不给全部文字统一倾斜 |
| 7 带声连续片段验证 | 用真实口播、已提供BGM和动作声测试前段→交接→后段；结尾也覆盖；对照V6的相关完整过程 | 关键帧放大、动态背景、空间、UI反馈、多样切镜、停稳阅读、揭示起点都实际成立；运动不越界、不挡脸；未成立先内部改，自主继续 |
| 8 扩展全片 | 内容/构图/运动/交接共同完成；逐秒查语义动态空档，连续看阅读与节奏；处理同类问题 | 不把原片人物自然运动或无关漂浮当包装；人物窗独立取景、原比例与遮罩同步；字幕不随人物缩放；不机械重复倾斜、翻页或左右换位 |
| 9 统一混音 | 从原声、BGM、动作声分轨混合，按事件匹配音色强弱；视觉修改同步调整动作声 | 人声优先、音乐退让、尾音自然；不在旧混音上反复叠加，不逐字堆声；响度/峰值不代替听感 |
| 10 三比例封面 | **完整执行规范第8节**：每期按主题重选单张参考→内置imagegen→三比例独立构图→身份/文案/空间/尺寸核对→保存并展示对应 | 不固定用骁龙图、不以平面拼图代替、不仅凑三比例；不达标先内部返修，生成尺寸/源文件边界如实说 |
| 11 最终实际检查 | 正常速度看完并试听、核字幕关键句；叠安全区查全片，风险转场查连续帧；检查实际编码、4K和缩小尺寸的字面/阴影 | 按第4节记录已检查/未检查/问题；已知越界和遮挡先修，不能用“待检查预览”绕过 |
| 12 交付与集中返修 | 提供可播放MP4、三封面、字幕、实际源文件/分轨/来源，侧栏打开预览，保留旧版 | 如实说明完成范围和真实编辑方式；局部反馈从受影响阶段返修，不重问整套确认，不重做无关部分 |

单句时间不足时简化演示，不为动画强行加速、延长或重排原声。代表片段可以同时覆盖多个观看任务，不要求先把全片静态页逐页定稿。

## 3. 工具：保留默认，按需调用

| 类别 | 默认/触发条件 |
|---|---|
| 默认指导 | lrh-packaging-plugin、项目AGENTS及Motion Craft/SRT对应阶段技能；动手前读取适用阶段 |
| 默认视频链路 | 本地Agent Motion、JS/HTML、Node.js、浏览器渲染、FFmpeg/FFprobe、已有转写及同步人物层工具；必要Python处理 |
| 空间实现 | Canvas/2.5D不足以表达时按场景选Three.js等；先验证代表片段，不以工具限制降低已要求质量 |
| 封面 | 默认内置imagegen并读相应技能，规范第8节为唯一详细规则 |
| adu及场景包 | 用户指定或具体场景确有收益时用，先核画幅/时长/素材/合成兼容；不默认双引擎 |
| 其他编辑器 | ChatCut、剪映/VectCut、Remotion、HyperFrames按用户指定软件/工程格式或明确能力缺口评估；不因已安装就迁移 |
| 专项特效 | 用户点名或明确需要对应能力时按需读；亮点特效1仅明确要求时调用，不批量加载1—13 |
| 参考查看 | 内置浏览器或本地视频；不打开用户抖音客户端；读取失败不冒称已观看 |
| 技能维护 | 更新技能入口时用skill-creator；不参与每期视频出片，不修改无关插件/模型配置 |

源码不等于剪映/AE原生时间线；已安装工具不等于实际调用，包装库索引不等于已有可调用组件。

## 4. 交付前检查：由制作方主动完成

**先过参考质量与强调项门槛。** 对照本期适用参考的实际连续过程，并逐项检查规范第1节。已有PLAN记录“参考片段/质量维度 → 本期对应片段 → 实际检查结果 → 发现问题与修复状态”。参考是最低标准；有明显退步或强调项漏做，返回相关阶段内部返修，不以技术通过、时间投入或预览标签当作质量通过。未能完成如实标明缺口，不声称合格交付。不增加用户逐项审批。

在已有PLAN用简短记录维护以下状态，不另造重复台账，不增加用户逐项审批。

- **边界与遮挡：** 对齐本期安全区依据，检查所有包装及字幕完整边界、入场、最大伸出/缩放、透视、阅读和接出；查人物脸、嘴、手势及文字互压。实际编码风险连续帧复核，提供可开关预览，最终成片不带线。
- **内容与动态：** 每句对应具体表达；开头不素；重点句放大；花字清楚；背景协调有空间；UI状态变化；切镜有变化、有接力、不突缩放或残留；强空间动作后回到可读状态。
- **声音与同步：** 正常速度全片观看、试听和关键字幕核听；说到才揭示，动作声落点正确，人声清晰，音乐不压话。
- **实际文件：** 全片解码、尺寸、帧率、帧数、音轨长度；人物原比例、同步遮罩、图文独立裁切与纹理无上一页残留；4K与手机尺寸都复核。
- **封面：** 选图及采用机制可追溯，三版独立排版且尺寸实测；本人身份、准确字句、道具体积与遮挡逐版检查；源材料真实可用，不冒称分层工程。
- **交付状态：** 技术检查、动态/听觉检查、用户认可分别记录。未检查项明确列出，不能继承旧片验收或用抽帧冒充全片观看。未完成必要视听只能标待检查预览；这一标识不能豁免安全区或保留已知问题。

修改字号、位置、镜头、人物、字幕或UI后，复查受影响段和邻接，并扫描全片同类问题。误把花字透视改成UI透视等情况先撤回误改，再修正确对象。

## 5. PLAN只记录本期，不重新定义规范

沿用已有PLAN，补齐：本期输入/规格/字体/BGM → 安全区依据 → 逐段语义和参考 → 动作交接及声音落点 → 素材来源许可/选择 → 封面选图和三版输出 → 实际检查与未完成项 → 用户反馈和版本。

具体颜色、窗口形状、人物/卡片时长比例、环绕时码及结尾样式不写成以后硬模板。合理复用已认可机制无需每次审批；新模块在全片中可供评议，获得明确认可才进入正式库，不把“做出来”当“已认可”。

长期变化合并到规范所属章节；流程只改步骤和检查时机；插件入口只指向这两份文件。本仓库旧版由Git历史保存，旧规则不作为现行并行来源。

参考统一入口为[全部视频与封面参考导航](reference-catalog.md)，包含阿杜、西子三条、V6、32段炫酷包装、切镜、封面合集和安全区依据；没有被用户否定的参考继续按语义选用，不因整理归档而停用。失效路径及候选新位置以导航状态为准。

用户2026-11-11确认的三组参考目录及全部文件见[目录清单](reference-catalog.md)，统一通过参考总入口按语义/实际问题调用；其中教学内容不自动覆盖用户要求或工具触发条件。
