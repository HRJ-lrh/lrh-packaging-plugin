# 视觉质量与参考迁移

此页把本机截至2026-11-06形成的UI、空间与连续交接要求转为可移植的检查方法。私人V6视频未随包公开；文字要求和原创示例均不意味着已经复制其画面或得到用户对新作品的认可。

## 先让主信息成立

- 分清第一眼要看的人物、数字、操作或结果。按实际观看尺寸检查；主信息偏小时可试放大30%—50%并减少外围装饰，再用真实画面判断，比例不是硬性标准。
- 主UI要有具体输入、内部结构、变化和结果。少量标题加细线、空矩形和纯色胶囊不能独自承担复杂知识点；不要靠假数据、假操作填空。示意和实际软件输出分别标明。
- 短标题可有性格，正文、步骤与字幕优先端正易读；保留必要的大小、字重和颜色分工。资料图先给全貌，再放大当前区域，不能整段依赖难读的小字。
- 对象的边缘、厚度、受光与接触影共同形成材质，辅助标签可以轻薄。原景灯光、卡片、内部图形与字幕放在完整构图中检查，避免近似颜色糊成一层，也不机械给全部对象加厚框。

## 动作必须交出结果

- 在已有PLAN中为关键段写“具体对象→变化→结果→交给下一段什么”。让步骤汇成工具、输入变为结果、选项筛出结论；避免全片统一“滑入—停留—消失”或整页翻转。
- 区分场景换位和信息揭示。关键词按对应口播词组起点出现；字幕或纹理里后半句不能提前露出。转写时间只是依据，改动后仍需核听。
- 翻转、人物窗和背景按实际空间关系随动；多对象的近远尺度、遮挡与视差须一致。单张歪卡或透视滤镜不自动等于整个场景具有纵深。
- 强运动用于揭示或交接，阅读处回正停稳。持续状态反馈应服务语义；加载圈必须交出对应结果，不靠无关旋转或背景漂浮填时长。逐秒检查有无失去视觉回应的空档，并连续观看强弱与阅读时间，不能机械每秒切镜。
- 人物全屏与小窗连续收放，保持比例并独立调整框内取景；脸、嘴、手势与字幕检查整个轨迹。原景窗口和换背景人物层按实际工程规则处理，不能混淆边框与人物描边。

## 代表段落的完成条件

先验证最难关系段和开场，能合为一段就合并；包含进入、揭示、阅读、交接及接出，按真实原声和已提供的BGM检查。以下任一项未成立，内部修订后再扩展，不新增用户逐段审批：

| 检查 | 可见证据 | 常见不合格情况 |
|---|---|---|
| 信息层级 | 缩小播放仍能立即找到当前重点 | 外框很大，内容很小 |
| UI交互 | 输入、状态变化和结果能对应 | 空卡片、无限加载、假操作 |
| 空间关系 | 多对象遮挡、视差、尺度同时合理 | 只把整幅画面倾斜 |
| 连续交接 | 重点对象身份、方向或阅读锚点延续 | 突然清空、跳位、叠出两个人物 |
| 动作节奏 | 强动作后有完整阅读窗口 | 持续摇晃、文字尚未读完就离开 |
| 人物与文字 | 原貌、取景、字幕位置保持清楚 | 人物被拉伸，字幕跟窗缩小 |

## 本包可运行参考

原创 `assets/quality-demo/` 包含三种连续机制：0—3秒步骤依次激活，3—4.5秒聚合为工具，4.5—8秒同一主对象放大交出结果并停稳。字幕保持屏幕位置。时间仅用于定位此示例，不能照搬到所有口播。

通过 `scripts/render-demo.mjs` 用实际 Agent Motion 运行环境渲染。场景使用几何占位人物与示意数据，无私人视频和音乐；它是可修改的交接/环境样例，不能作为真人取景、抠像、语音同步或整片审美已经通过的证据。原源码保留在引擎 `work/lrh-check-*`；正常浏览器可循环预览，`?capture=1` 支持绝对时间导出。

用户提供有权使用的参考时，在PLAN记录文件/来源、准确时段、学习机制与不照搬项。实际查看对应连续过程，排除播放器标尺和教程操作；缺少参考视频时明确说明，不声称已经对照V6或某位博主的完整作品。

## 三类检查分别记录

1. **技术**：环境、解码、尺寸、帧率、时间线、音轨、确定性渲染。脚本通过仅支持这一层。
2. **视听**：连续正常速度观看、实际试听、阅读停留、空间交接、真人边缘和词组同步。未完成写“待检查”及具体范围，不用抽帧替代整片视听。
3. **用户认可**：只记录用户明确认可的版本和对象；旧片或参考方向的认可不自动授予新片。

每期在现有PLAN或交付记录保留源码、渲染命令、输出版本、具体检查范围和剩余问题。不要为本页额外堆叠多份重复台账。
